## 📝 Sobre o Projeto

O **Batalha dos Elementos** é um jogo interativo desenvolvido inteiramente com tecnologias web nativas (HTML5, CSS3 e JavaScript). O projeto foi criado com o objetivo de praticar conceitos de lógica de programação, manipulação de eventos no DOM (Document Object Model) e desenvolvimento de mecânicas de jogos 2D simples diretamente no navegador.

## 🕹️ Como Jogar

Como o projeto já possui o deploy ativo via GitHub Pages, basta seguir os passos abaixo:

1. Acesse o link do jogo clicando [aqui](https://pernisa2.github.io/Batalha-dos-elementos/).
2. O jogo abrirá diretamente na sua tela.
3. Siga as instruções da interface para interagir com a batalha de elementos!

*Se preferir rodar localmente:*
1. Faça o download ou clone este repositório.
2. Dê um duplo clique no arquivo `index.html` para abrir o jogo no seu navegador de preferência.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação da interface e dos elementos do jogo.
* **CSS3:** Estilização visual, cores, responsividade e layout da arena de batalha.
* **JavaScript (ES6):** Toda a inteligência do jogo (regras da batalha, controle de pontuação, lógica dos elementos e interações do usuário).
